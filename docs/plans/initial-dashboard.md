# Initial dashboard

## Goal

Create a voice-first daily nutrition dashboard around Joe's normal Sainsbury's shop.

## First version

- Fixed calorie, protein, carbohydrate, fat and fibre targets.
- Natural-language meal preview and logging.
- Voice transcription where supported by the browser.
- Daily totals, remaining macros and clear fit/adjust guidance.
- Device-local daily history and removable meal entries.

## Verification

- Production build and rendered-output tests.
- Verify the seeded Monday lunch uses 192g cooked chicken, a complete 130g sticky-rice pot and 20g PERi-PERi sauce.
- Verify the dashboard updates after logging and removing a meal.
